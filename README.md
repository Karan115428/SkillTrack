# SkillTrack Starter Project

A beginner-friendly front-end starter for a Skill Assessment and Recommendation System.

## Pages
- `index.html` — demo login
- `dashboard.html` — learner dashboard
- `roles.html` — role selection and search
- `assessment.html` — short role-based multiple-choice quiz with a result
- `profile.html` — learner profile form
- `css/style.css` — shared responsive styling
- `js/app.js` — page interactions and demo browser storage

## Run locally
1. Extract the ZIP.
2. Open the `skilltrack-starter` folder in VS Code.
3. Open `index.html` in your browser, or use the VS Code Live Server extension.
4. Sign in using any valid-looking email and a password of at least 4 characters.

## Important limitations
This is a front-end learning starter, not production authentication. It stores profile/demo progress in `localStorage`, which is specific to the browser. Passwords are not saved. Do not use real passwords or sensitive information. A real app needs a backend, database, server-side validation, secure authentication, and authorization.
